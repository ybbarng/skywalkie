# 화면 미리보기

두 폰을 나란히 놓고 실제로 어떻게 보이는지 확인하는 데모다.

```
open demo/index.html
```

파일 하나만 열면 된다. 서버도 설치도 필요 없다.

## 앱이 아니다

**진짜 코드를 돌리는 게 아니다.** 같은 색·같은 문구·같은 캐릭터로
흐름만 흉내 냈다. 기기 없이 화면이 어떻게 보이는지 보려고 만들었다.

| | 어디서 가져왔나 |
|---|---|
| 색 | `src/presentation/theme/colors.ts` 와 같은 값 |
| 문구 | `src/presentation/copy/` 와 같은 말 |
| 캐릭터 | `src/presentation/characters/` 와 같은 그림 |

바깥에서 아무것도 불러오지 않는다.

## 해볼 수 있는 것

**한쪽에 글을 쓰면 반대쪽으로 건너간다.** 읽음 표시(✓✓)와 입력 중
표시도 그대로 돈다. 답장도 온다.

위 단추로 상황을 바꾼다.

- **처음 이어지기** — 서로 다른 안내가 뜬다. 여는 쪽은 핫스팟을,
  붙는 쪽은 Wi-Fi 이름을 본다
- **대화 중** — 말풍선, 이모티콘, 날짜 구분선, 읽음 표시
- **핫스팟 꺼짐** — 끊겼을 때 양쪽에 각각 무엇이 뜨는지
- **통화** — 거는 쪽과 받는 쪽 화면이 다르다
- **입력 중 / 이모티콘 / 배터리 / 밝은 화면**

## 진짜와 다른 점

흐름만 흉내 낸 것이라 이런 것은 여기 없다.

- 실제 연결, 저장, 동기화
- 사진 주고받기, 낙서 그리기
- 끊겼다 붙을 때 놓친 말 되찾기

그건 `pnpm test` 가 확인한다. 이 파일은 **눈으로 볼 것만** 담는다.
