# T20 — 블루투스 보조 경로

**단계** 보조 · **상태** 대기 · **먼저** T09

## 목표

핫스팟을 못 쓰는 상황에서도 **글로는 대화할 수 있다.** 항공사가 개인 핫스팟을 금지할 수 있기 때문에 만든다.

## 근거

[04-transport-spec.md](../04-transport-spec.md) 4장 · [01-product-spec.md](../01-product-spec.md) C3

## 먼저 알아둘 것

**자주 쓰는 `react-native-ble-plx`는 찾는 쪽만 할 수 있다.** 알리는 쪽은 마땅한 라이브러리가 없어 **아이폰용 네이티브 모듈을 직접 만들어야 한다.** 이 공수 때문에 이 카드가 뒤로 밀려 있다.

## 할 일

```
modules/ble-peripheral/         직접 만드는 네이티브 모듈
  ios/BlePeripheralModule.swift    CBPeripheralManager. 200줄 안쪽
  src/index.ts

src/infrastructure/transport/ble/
  BleMessageTransport.ts
  BlePeripheral.ts          아이폰: 알린다
  BleCentral.ts             안드로이드: 찾는다
  chunk/
    Chunker.ts              긴 메시지를 조각내기
    Reassembler.ts          다시 붙이기
  Compressor.ts             보내기 전에 압축
```

### 역할

| | 역할 | 왜 |
|---|---|---|
| 아이폰 | 알리는 쪽 | iOS는 화면이 꺼져도 제한적으로 알림을 계속한다 |
| 안드로이드 | 찾는 쪽 | 안드로이드는 찾는 동작에 제약이 적다 |

Wi-Fi와 역할이 반대다. 각 운영체제가 잘하는 쪽에 맞췄다.

### 식별자

[04-transport-spec.md](../04-transport-spec.md) 4.2의 UUID 다섯 개를 그대로 쓴다.

### 조각내기

한 번에 보낼 수 있는 크기가 작다. 아이폰 185바이트, 안드로이드 최대 517바이트. 협상한 값에서 3바이트를 뺀 만큼씩 자른다.

```
┌────────┬────────┬────────┬─────────────────┐
│ 묶음번호│ 조각   │ 전체   │ 내용            │
│ 1바이트 │ 1바이트│ 1바이트│ 나머지          │
└────────┴────────┴────────┴─────────────────┘
```

- 한 메시지는 최대 255조각, 약 46 KB
- 보내기 전에 압축한다. 한국어는 절반 이하로 준다
- 마지막 조각 뒤 5초 안에 조립이 안 되면 그 묶음을 버린다

### 여기선 못 하는 것

명확히 막고 왜 안 되는지 알린다.

- **음성·영상**: 대역폭이 백분의 일이다. "지금은 글로만 이야기할 수 있어요"
- **낙서·사진**: 크기가 커서 대기시킨다. "Wi-Fi가 연결되면 보낼게요"
- **입력 중 표시**: 아예 보내지 않는다. 좁은 길을 실제 대화에 양보한다

### 속도

초당 2~5 KB다. 긴 글은 몇 초 걸린다. 화면에 보내는 중 표시를 띄운다.

## 테스트

**컴퓨터에서**
- 조각내고 다시 붙이면 원래 값과 같다 (여러 크기로)
- 조각 하나가 안 오면 그 묶음을 버린다
- 조각이 뒤바뀌어 와도 올바로 붙는다
- 압축하고 풀면 원래 값과 같다
- 46 KB를 넘으면 거절한다
- 블루투스 상태에서 음성·낙서·사진이 막힌다

**실제 기기로**
- 두 폰이 블루투스로 붙는다
- 글이 오간다
- Wi-Fi가 열리면 자동으로 갈아탄다 (T09)

## 끝난 걸 어떻게 아는가

- [ ] 핫스팟 없이 블루투스만으로 대화가 된다
- [ ] Wi-Fi가 열리면 메시지를 흘리지 않고 갈아탄다
- [ ] 못 하는 기능이 명확히 막히고 이유가 설명된다
