# T02 — 디자인 토큰과 밝기 모드

**단계** 기반 · **상태** 완료 · **먼저** T01

## 목표

색·글자·간격을 한곳에 모으고, 밝은 화면과 어두운 화면이 자동으로 바뀐다. 이 뒤로 만드는 모든 화면이 이 토큰만 쓴다.

## 근거

[07-design-system.md](../07-design-system.md) 2~5장

## 할 일

### 토큰 정의

```
src/presentation/theme/
  colors.ts        어두운/밝은 두 벌
  typography.ts    글자 크기와 굵기
  spacing.ts       간격과 모서리
  motion.ts        움직임 시간
  tokens.ts        위를 하나로 묶은 타입
```

색 값은 [07-design-system.md](../07-design-system.md)의 표를 그대로 옮긴다.

### 테마 공급

```ts
const { colors, typography, spacing } = useTheme()
```

- 기본은 기기 설정을 따른다 (`useColorScheme`).
- 설정에서 고른 값이 있으면 그것을 우선한다.
- 고른 값은 기기에 저장한다.
- 바뀔 때 0.2초에 걸쳐 색이 서서히 변한다.

### 기본 부품

토큰만 쓰는 부품 몇 개를 먼저 만든다. 이 뒤로 화면을 만들 때 이것들을 조립한다.

```
src/presentation/components/
  Text.tsx           글자 이름(body, caption 등)으로 쓴다
  Button.tsx         누르면 0.96배로 줄었다 돌아온다
  Card.tsx
  Sheet.tsx          아래에서 올라오는 것
  HelpTip.tsx        물음표. 누르면 설명이 뜬다
  Icon.tsx           SVG 아이콘 모음
```

`HelpTip`이 특히 중요하다. [07-design-system.md](../07-design-system.md) 8장의 "처음 쓰는 사람을 위한 장치"가 여기서 시작된다.

### 설명 문구 모으기

```
src/presentation/copy/help.ts
```

물음표를 눌렀을 때 뜨는 글을 전부 여기 모은다. 화면 코드에 글이 흩어지면 나중에 다듬기 어렵다.

### 움직임 줄이기

기기에서 "동작 줄이기"를 켠 사람에게는 모든 움직임을 없앤다. `useReducedMotion`을 한 번 만들어 모든 부품이 쓰게 한다.

## 끝난 걸 어떻게 아는가

- [x] 기기 설정을 바꾸면 앱 색이 따라 바뀐다
- [x] 앱 안에서 밝기 모드를 고르면 그게 유지된다
- [x] 두 모드 모두에서 글자와 바탕의 대비가 4.5대 1 이상이다 (테스트로 확인)
- [x] "동작 줄이기"를 켜면 움직임이 사라진다
- [x] 화면 코드에 `#` 로 시작하는 색이 하나도 없다 (`pnpm check:tokens`)

## 하면서 알게 된 것

### 밝은 화면의 말풍선 색을 진하게 바꿨다

처음 고른 색(`#E8722B`, `#0C8FD4`)은 흰 글자를 얹었을 때 대비가 3.1과 3.6에
그쳤다. 눈으로는 괜찮아 보였지만 기준에 못 미친다. `#C2410C` 와 `#0369A1` 로
진하게 바꿔 5.2와 5.9를 확보했다.

**눈대중으로 판단하지 않은 게 값을 했다.** 대비를 재는 테스트가 없었다면
밝은 화면에서 말풍선 글자가 흐린 채로 비행기에 탔을 것이다.

`textFaint` 와 `warning` 도 같은 이유로 조금 어둡게 옮겼다.

### 잘못된 기준 두 개를 고쳤다

- **경계선에 글자 기준을 들이댔다.** 경계선을 4.5대 1로 맞추면 어두운 화면이
  그물처럼 보인다. 장식이므로 "있다는 걸 알아볼 정도"인 1.1로 낮췄다.
- **말풍선 구분을 밝기로 쟀다.** 주황과 파랑은 밝기가 비슷해서 대비는 1.1밖에
  안 나오지만 실제로는 전혀 헷갈리지 않는다. 구분하는 건 밝기가 아니라 색이다.
  그래서 색상환에서의 거리(`hueDistance`)로 재도록 바꿨다.

### 색 직접 적기를 막는 검사를 따로 만들었다

`scripts/check-tokens.ts`. biome 규칙으로는 잡을 수 없어서 직접 만들었다.
